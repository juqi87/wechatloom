# WeChatLoom v0.2：本地视觉系统

`0.2.0-dev` 完成 Markdown 到公众号本地预览的视觉主链，仍不包含微信远程写入。

## 已交付

- 6 个原创主题家族、24 套主题；每套主题包含完整颜色、字体、字号、行高、间距、边框、圆角、阴影、代码和图注变量。
- 24 个布局组件；每个组件都有严格 JSON Schema、有效示例和错误示例。
- 通用 `:::wx-*` parser，支持必填项、枚举、列表、嵌套对象、未知字段、嵌套组件和未闭合组件诊断。
- 主题化 GFM、表格、引用、代码、链接、图片和全部组件渲染；输出使用公众号兼容内联样式。
- 相对本地图片解析、内容哈希命名和只读构建资产。
- 离线公式 PNG 和安全 Mermaid flowchart 子集，包含缓存键、`alt` 和源行诊断。
- 可切换 24 主题与 320/375/430 手机宽度的单文件预览 UI。
- 仅监听 `127.0.0.1` 的只读预览服务；只开放预览与已解析资产。
- Chrome、Chromium、Edge 发现和 2× PNG 截图；缺少浏览器时不影响 HTML 构建。
- 主题 `list/show/validate/install/export`，项目主题覆盖和冲突保护。
- 组件 `list/show/export`，可一次导出 24 份 schema 与正反例。
- 构建 manifest 记录完整主题 token、组件 schema、资源哈希和产物哈希。
- 可移植 Codex Skill，支持自动主题推荐、少量组件编排、构建、预览和截图。

## 安全边界

- `inspect`、`build`、`preview`、`snapshot` 均不访问微信、不上传正文、不创建草稿。
- 原始 Markdown 默认只读；自动编排应写派生稿，除非用户明确授权修改原稿。
- 主题包只允许数据，不允许脚本、远程字体或可执行模板。
- Mermaid 禁止 URL、点击处理、样式注入和可执行标记。
- 项目配置不接受账号密钥；v0.2 没有微信凭证字段。

## 明确限制

- Mermaid 是面向公众号稳定性的安全 flowchart 子集，不是完整 Mermaid 语言实现。
- 公式是本地确定性排版器，支持常用显示表达式、上下标、常见符号、简单分数与平方根，不运行完整 TeX 宏系统。
- 本地图片会进入构建资产；微信素材上传、远程图片下载、封面和草稿发布属于 v0.3。
- PNG 像素基线与浏览器、操作系统字体有关；仓库基线记录 Chrome 150/macOS，CI 另产出固定 Chrome 150/Linux 的 smoke artifact。

## 验收证据

- Catalog 测试验证 24 主题、6 家族、24 组件、schema、正反例和对比度。
- Builder 测试让每一套主题渲染完整组件画廊，并要求 24 个不同内容哈希。
- 公式、Mermaid、代码、表格和本地图片拥有专项构建测试。
- 预览服务测试覆盖 loopback、GET/HEAD、POST 405、manifest 隔离和资产白名单。
- 截图测试固定 320/375/430、1000 高度和 2× 比例。
- 浏览器像素回归允许显式运行，基线不得由测试自动接受。
