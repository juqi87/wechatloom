# WeChatLoom 1.0.0 acceptance record

Date: 2026-08-05 (Asia/Shanghai)

This record separates completed release-candidate evidence from gates that still require a real external environment or explicit remote-write consent.

| Gate | Result | Evidence |
| --- | --- | --- |
| Version identity | Pass | Native macOS and clean Linux executions returned tool version `1.0.0` from `capabilities --json`. |
| Local quality | Pass | `go test -race ./...`, `go vet ./...`, command build, actionlint, GoReleaser configuration check, and the checked-in visual regression test passed. |
| Official Account token | Pass | The configured `personal` account was verified against the official endpoint; the response exposed only masked AppID `wxec…017c` and a 7200-second token lifetime. |
| Draft safety gate | Pass | A real-account `add` dry-run validated the build, cover, account binding, content hash, persisted plan, expiry, and expected effects without a remote write. |
| Real draft add/update | Pass | The configured non-production account returned confirmed outcomes for both `add` and `update`. The update preserved the same remote media identity and content hash. Deliberately inducing an ambiguous network loss is covered by automated recovery tests rather than a destructive live fault. |
| macOS distribution | Pass on amd64; arm64 build pass | Standalone amd64 and arm64 Mach-O files were produced; amd64 executed natively and returned `1.0.0`. An arm64 host is still needed for native execution. |
| Linux distribution | Pass | Statically linked amd64 and arm64 binaries executed successfully in clean Alpine 3.22 containers and returned `1.0.0`. |
| Windows distribution | Pass | GitHub `windows-latest` built the amd64 command, ran the full race suite, installed a real `1.0.0` binary through the PowerShell installer, and executed its capabilities protocol. |
| Installer trust | Pass | Unix and Windows contracts reject repository redirection, require checksum-matching content from `juqi87/wechatloom`, install the produced binary, and execute it as version `1.0.0`. |
| Windows credential ACL | Pass | GitHub `windows-latest` accepted a private config and rejected a config granted `Everyone:R`. The production check also rejects every readable ACE outside the documented privileged principals. |
| Theme rendering | Human sign-off pass; real WeChat preview pending | All 24 themes produced 320, 375, and 430 px snapshots (72 images). No missing artifact or visual baseline regression was detected, and the user accepted the visual overview. The created draft still needs a final preview inside WeChat before tagging. |
| Release signing | Configuration pass | GoReleaser validates keyless Cosign signing for `SHA256SUMS`; the tag workflow must produce and verify the actual Sigstore bundle. |

The 1.0.0 tag and GitHub Release must not be created while any required gate above remains pending.
